# Frontend AI settings (vague-prompt version)

This repository contains a drill from the Frontend AI Engineering Internship. The goal is to demonstrate the difference between building with vague AI prompts versus precise, spec-driven prompts.

React + Vite Settings Form

This is a minimal React + Vite project that contains a simple settings form with validation.

Getting started

1. Install dependencies:

   npm install

2. Start dev server:

   npm run dev

3. Open the app at the URL shown by Vite (usually http://localhost:5173)

What is included

- A small form with fields: username (required, min 3 chars), email (required, basic email format), enable notifications (checkbox), update frequency (select).
- Client-side validation with inline error messages.

Notes

This repository intentionally keeps the setup minimal. If you want TypeScript, testing, or more advanced validation libraries, these can be added on request.
